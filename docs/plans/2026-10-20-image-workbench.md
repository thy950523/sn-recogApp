# 图片查看与裁剪

用户确认：在识别结果页、登记记录中提供图片查看与裁剪，显示当前 OCR 的全部文字框，辅助判断原图的裁剪范围，并控制 Excel 体积。

- 沿用现有黑色表面、直角控件、黄色主操作与绿色 OCR 标注。工具区、原图工作区、文字/导出预览区、固定底部确认操作；桌面左右排列，手机上下排列。
- 完整原图与全部真实 OCR 行坐标关联；无真实坐标时明确提示，不绘制合成坐标。支持 1–4 倍放大、触摸/鼠标框选、百分比键盘输入、按全部文字框选择、恢复整图。
- normalized Box4 裁剪范围按登记记录保存，原始 Blob 不变。识别页的选择应用于该次登记的记录；登记后可逐条调整。旧数据的裁剪与 OCR 行字段均可缺省。
- 默认精简 JPEG，另有清晰、原图与仅文字导出。先裁剪再缩放编码，单张目标为 180/600 KiB，压缩工作有界；不保证每张严格达标。按 imageId + 归一化 crop 去重，避免错误复用不同裁剪图。
- 裁剪预览为真实精简衍生图与字节数，Excel 完成后展示真实下载字节数。异步预览作废与 URL 释放必须覆盖快速改选、关闭、切图。
- 验证几何边界、源像素裁剪、限次压缩、原图保真、Excel ZIP 内图片去重/区分、仅文字无图片读取，以及真实照片桌面/手机操作。

本次导出设置以用户最新的控制 Excel 大小需求为准，取代先前“所有导出默认原图”的策略；原始照片存储策略不变。
